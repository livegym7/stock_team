## 2. 현재 화면의 문제 7가지

| # | 문제 | 어디서 보이나 |
|---|---|---|
| 1 | **메뉴가 '데이터 출처'별**(채널·자료실·기업·브리핑)로 나뉘어 있어, "오늘 뭘 봐야 하지?"라는 질문에 답하려면 4~5개 메뉴를 돌아야 함 | 전체 |
| 2 | 같은 소식이 **4곳에 흩어져 반복**: 오늘>중요한 소식, 브리핑>채널 정리, 채널 원문, 전략 보고서 근거 | 오늘·브리핑·채널 |
| 3 | **오늘 화면이 휴대폰에서 거꾸로**: 시장 온도계 표 → 해외 표 → 그 다음에야 💡 의견. 가장 중요한 Claude 판단이 두 번 스크롤 뒤에 있음 | 오늘(모바일) |
| 4 | **보유 0인데 포트폴리오 공간이 큼**: 오늘 오른쪽 열(내 계좌·보유·일정)과 포트폴리오 메뉴 대부분이 빈 표. 반대로 지금 필요한 '손절 복기'는 매매 일지 표 한 줄뿐 | 오늘·포트폴리오 |
| 5 | **브리핑 메뉴는 파일 고르기 상자**(드롭다운)라서 흐름이 안 보임. 2시간마다 채널 정리·리포트 정리가 쌓여 하루 최대 10개 | 브리핑 |
| 6 | **자료실 탭 5개가 역할이 섞임**: 문서(원문 요약) + 네이버 후보 + 성적표 + 지난 종합 + 리포트 흐름. '리포트 흐름'은 기업·소식 쪽 내용 | 자료실 |
| 7 | **규칙·일정이 세 가지 질문을 한 화면에**: 달력(언제?) + 매매 규칙(어떻게?) + 자동 작업 현황(시스템 상태?) | 규칙·일정 |

그 밖에: 전략 보고서 → 관찰 섹터 → 기업 → 감시 목록으로 이어지는 **'다음 행동' 연결이 끊김**(감시 목록이 꺼져 있고, 전략 보고서의 기업 지도가 기업 메뉴로 이어지지 않음). 새로고침 ↻ 버튼은 실제로 아무것도 안 하고 안내 글만 보여서 헷갈림. 페이지 한 장에 사진까지 넣어 약 4MB → 휴대폰에서 느림.

## 4. 새 구조안: 메뉴 5개 (휴대폰 탭 4 + 더보기)

```
오늘        흐름        전략        내 매매     ⋯ 더보기(일정·설정)
 ①           ②           ③           ④             ⑤
```

### ① 오늘 — "지금 장은 어떤 상태고, 오늘 무엇이 중요한가?"
한 열로 위에서 아래로. 휴대폰에서 **처음 한 화면 안에 신호등 + 의견**이 들어오게.
1. 머리줄: 날짜 · 🟢🟡🔴 시장 신호 한 줄(코스피 20일선 기준) · 데이터 기준 시각
2. 💡 Claude 의견 4줄(핵심 · 내 종목 · 반대 근거 · 🔄 변화) — 가장 최근 브리핑
3. 📌 중요한 소식 5개(최신 채널 정리의 번호 주제) → 누르면 흐름 메뉴 해당 글
4. 📅 오늘·내일 일정 3개(달력 중요한 순)
5. 시장 숫자: 코스피·코스닥 미니 차트 + 투자자 수급 + 해외 9개 — **접어 둔 상자**(한 번 펼치면 기기에 기억)
6. 💼 내 계좌 한 줄: 보유 있으면 종목 수·평가손익·CR, 없으면 "보유 없음 · 최근 손절 5건 → 내 매매에서 복기"
PC는 2단: 왼쪽 2~4, 오른쪽 5~6. 지금 3단에서 줄임.

### ② 흐름 — "무슨 이야기가 돌고, 리포트는 어디를 올리고 내리나?"
브리핑 + 채널 + 리포트 흐름을 **하나로 합침**. 위에 탭 3개.
- **정리** (기본): 날짜별 타임라인. 하루 안에서 아침 → 채널 정리 10시·12시… → 리포트 정리 → 마감 리뷰 순으로 카드. 카드 머리에 💡 첫 줄만 보이고 누르면 본문 펼침. 지난날은 종류별 마지막 1개만(지금 규칙 그대로). 종류 필터 칩(아침·채널·리포트·리뷰) 유지.
- **리포트**: 기간 머리줄 `🔺상향 a · 🔽하향 b · 🆕 c · ➖ d`, 섹터별 상향·하향 막대, 종목별 목표가 변경 표(증권사·전→후). 지금 자료실>리포트 흐름(revFlow)과 기업 상세의 증권사 표를 여기로.
- **채널 원문**: 지금 채널 메뉴 그대로(분류·채널 필터, 텔레그램식 카드). 사진은 **누를 때 불러오기**로 바꿔 페이지 무게를 줄임. 채널 성향 표는 더보기>설정으로 이동.

### ③ 전략 — "어느 섹터·테마가 좋고 왜인가? 그 안에서 어떤 기업을 보나?"
전략 보고서 + 자료실 + 기업을 **한 메뉴 안의 탭 3개**로.
- **보고서** (기본): 지금 전략 보고서 화면 그대로(한 장 요약 → 띔 → 관찰 섹터 → 성적표). 띔의 '기업 지도'에 나온 종목 이름을 누르면 **기업 탭으로 이동**(연결 복원). 보고서 날짜·"지난 보고서 보기".
- **자료실**: 문서 목록(주제 묶음·검색·기간)만. 네이버 후보·지난 종합·성적표는 '보관' 접기 안으로. 문서 상세에서 "이 리포트가 언급한 기업" → 기업 탭.
- **기업**: 지금 기업 메뉴(목록 + 상세: 사업 한 줄·가격·RS·같은 업종 비교·컨센서스·최근 리포트). 필터에 **"전략 보고서 기업 지도 종목만"** 추가 → 사실상 '관찰 목록' 역할. 모니터링을 다시 켜면 감시 목록이 이 자리에 네 번째 탭으로 돌아옴.

### ④ 내 매매 — "내 돈은 어떤 상태고, 규칙상 다음 행동은?"
포트폴리오 + 매매 규칙 + 복기.
1. 계좌·리스크 4칸(E·CR·새로 걸 수 있는 위험·수익률) + 수익률 vs 코스피 그래프
2. 보유 종목(있을 때만 표 + 다음 액션 카드. 없으면 한 줄)
3. **📒 매매 복기**(새로 강조): 최근 매매 일지 표 + 거래별 R + **손절 묶음 메모**(예: 11/05~06 5건 연속 손절, 3건은 −1R, 2건은 갭하락으로 −1.5R·−1.9R. 11/04 3종목 같은 날 매수 뒤 급락. 그날 신호등 색은? 업종 동반 상승은 있었나?) — 숫자는 일지에서, 해석은 마감 리뷰 '띔 메모'에서 가져옴. 사고 나서 규칙을 지켰는지 ✅/⚠️ 표시.
4. 살 수 있는 수량 계산기(그대로)
5. 📌 매매 규칙 한 장(rules.md, 고정 기간 표시) — 지금 규칙·일정에서 이동
감시 목록·검증실은 모니터링 켤 때 여기 또는 ③에 탭으로(결정 사항 2).

### ⑤ 더보기 (일정·설정)
- 📅 달력(월간·분류·⭐ 관련 종목만) + 채널 일정 글
- ⚙️ 자동 작업 현황 + 데이터 출처·기준 시각 + 지키는 선
- 📡 채널 목록·성향 표(30일)
- ☀/☾ 화면 모드. **새로고침 버튼은 없앰** → 상단 기준 시각 옆에 "다음 자동 갱신 HH:MM" 글자만

### 휴대폰에서 보는 순서 (하루 흐름)
- 아침 07~09시: **오늘**(신호등·의견·소식) → 흐름>정리(아침 브리핑 본문)
- 장중: **오늘** 머리줄만 → **내 매매**(보유 있을 때)
- 저녁 16~20시: 흐름>정리(마감 리뷰) → 흐름>리포트(오늘 상향·하향) → **전략**>자료실(오늘 새 요약)
- 주말: **전략**>보고서 → 기업

## 5. 데이터 연결 (web_build.py 데이터 → 화면)

대부분 지금 키를 그대로 쓰고, 새로 만드는 건 3개입니다.

| 화면 | 쓰는 데이터 키 | 바뀌는 것 |
|---|---|---|
| 오늘 | `insights.regime`, `briefs[0].opinion`, 최신 채널 정리 번호 주제, `calendar`, `market`·`pulse`, `risk` | 없음(배치만) |
| 흐름>정리 | `briefs`(kind·date·time·text·opinion) | **날짜별 묶음**은 화면에서 계산 |
| 흐름>리포트 | `report_flow`, `companies[].reports/rev` | 없음 |
| 흐름>채널 | `channels`, `categories`, `channel_stats` | 사진 `thumbs`를 **별도 파일**(Artifact `files`)로 빼서 본문 1MB 안쪽 목표 |
| 전략>보고서 | `strategy`(latest.json) | 기업 지도 종목 → `companies` code 연결(이름→코드 표) **새로 추가** |
| 전략>자료실 | `research.docs`, `research.naver`, `research.synthesis` | 없음(탭 접기) |
| 전략>기업 | `companies`, `earnings`, `cons` | 필터 "보고서 기업 지도" **새로 추가**(strategy에서 이름 모음) |
| 내 매매 | `risk`, `trades`, `equity`, `account` | `trades`에 **손절 묶음 요약**(연속 손절 수·날짜·평균 R·그때 신호등 색) 새로 추가 — `trades.py summary`에서 계산, 토큰 0 |
| 더보기 | `calendar`, `automation`, `channel_stats`, `schedule` | 없음 |

- 도구 쪽 수정은 `tools/web_build.py`(데이터 3개 추가)와 `tools/trades.py`(복기 요약)만. 수집 도구·예약 작업은 그대로.
- `web/app.html`은 메뉴(MENU·GROUPS·TABS·VIEWS)와 오늘·흐름·전략·내 매매·더보기 5개 화면 함수를 새로 쓰고, 안쪽 블록(브리핑 꾸미기 briefHtml, 기업 상세, 달력, 전략 보고서 본문, 채널 카드)은 **지금 함수를 그대로 재사용**합니다. 디자인(shadcn 스타일, 빨강 오름·파랑 내림, Noto Sans KR)은 유지.
- 브리핑 글쓰기 규칙(docs/brief-style.md)·스킬·예약은 바뀌지 않습니다.

## 6. 구현 순서 (확인 뒤)

1. `app.html` 메뉴 5개 + 오늘 화면 한 열 재배치 (하루)
2. 흐름 메뉴(타임라인 + 리포트 탭 + 채널 탭) — 기존 블록 재사용
3. 전략 메뉴(보고서·자료실·기업 탭) + 기업 지도 → 기업 연결
4. 내 매매(복기 요약 추가, `trades.py`) + 더보기
5. 사진 별도 파일로 분리(페이지 무게) → 로컬에서 `web_build.py` 실행해 확인 → 사용자 확인 뒤 Artifact 재발행

## 7. 결정해 주실 것

1. **채널 원문 피드를 남길까요?** 흐름>채널 탭으로 두는 안(기본)과, 아예 빼고 '정리' 글만 남겨 페이지를 가볍게 하는 안이 있습니다. 원문을 직접 훑는 습관이 있으면 남기는 쪽이 맞습니다.
2. **기업을 전략 아래 탭으로 넣을까요, 따로 메뉴로 둘까요?** 탭으로 넣으면 메뉴 5개(제안). 종목 이름으로 바로 찾는 일이 잦으면 '기업'을 독립 메뉴로 두고 메뉴 6개(휴대폰 탭: 오늘·흐름·전략·기업 + 더보기, 내 매매는 더보기로)가 낫습니다.

(참고) 모니터링을 다시 켤 때 감시 목록·검증실은 **전략 메뉴의 탭**(후보 → 감시 흐름이 자연스러움)으로 넣는 것을 기본으로 생각하고 있습니다. 다르게 원하시면 알려 주세요.
