# 전략 보고서 형식 v3 — 전문 애널리스트 양식 (2026-11-10)

증권사 전략 리포트(Investment Strategy)의 뼈대를 따른다. **결론 → 근거 → 반론 → 무효 조건 → 행동 체크리스트** 순.
파일: `data/strategy/latest.json` (저장은 `python3 tools/strategy_prep.py save --file 초안.json`이 형식을 검사하고 지난 호를 `data/strategy/history/`에 보관).
웹 '전략 > 보고서'가 이 JSON을 그대로 그린다. 텔레그램에는 `summary`만 보낸다.

## 지켜야 할 것
- 매수·매도를 단정하지 않는다. 행동은 **관찰 / 준비(셋업 대기) / 회피** 세 단어로만 쓴다. 판단은 사용자가 한다.
- 숫자마다 **출처와 기준 시각**. 채널 요약은 "(채널 요약)", 리포트 요약은 "(증권사 날짜)", 원문 확인은 "(증권사 날짜 p.n, 원문 확인)".
- 매매 규칙(docs/rules.md)은 2027-01-31까지 고정. 규칙을 바꾸자는 말을 쓰지 않는다. 신호등별 '권장 노출'은 **표시만**.
- 글은 `docs/brief-style.md` '읽기 쉬운 글쓰기'(한 문장 60자 안팎, 결론 먼저, 괄호 1개).
- 31일 치 채널 글 원문을 다시 읽지 않는다. 재료는 `strategy_prep.py prep`의 숫자 + 자료실 요약 + 띔 메모 + 최근 의견. 원문 확인은 네이버 리서치 `pdf`로 **최대 3건**.

## 4검증 점수 기준 (0~2점, strategy_prep 숫자 기준)
| 축 | 2점 | 1점 | 0점 |
|---|---|---|---|
| 말 | 이번 주 글 수가 4주 평균의 1.5배↑ **또는** 2주 연속 증가 | 평균 수준 | 감소·거의 없음 |
| 이익 | 7일 상향 > 하향 **그리고** 실적 서프라이즈 있음 | 상향·하향 비슷하거나 컨센 유지 | 하향 우세·쇼크 |
| 가격 | 업종 5일·20일 수익률 모두 코스피보다 높음 **그리고** 선도주 RS 80↑ | 하나만 충족 | 둘 다 미달 |
| 돈 | 외국인·기관 5일 합계 순매수 **그리고** 연속 매수일 2일↑ | 한쪽만 순매수 | 둘 다 순매도 |

단계: 초기(말↑ 가격→) · 확산(말↑ 이익↑ 가격↑) · 과열(가격↑↑ 말↑↑ 돈 둔화, 컨센 괴리 축소) · 소멸(가격↓ 말↓).
