# 전략 구성 v1 (2026-11-02)

기본 원칙: **큰 그림 → 작은 그림** 순서로 좁혀 간다. 각 단계는 다음 단계의 "필터"다.
시스템은 정보·신호·알림만 만든다. **주문은 하지 않고, 판단은 사용자가 한다.**

```
① 시장 분위기 → ② 시장 지표 → ③ 섹터 강도 → ④ 셋업 스크리닝 → ⑤ 기업 이해
 (채널·뉴스)     (지수·수급·매크로)  (ETF·업종)      (추세추종 규칙)      (사업개요·실적)
```

## ① 시장 분위기 — "사람들이 지금 무슨 얘기를 하나"
| 항목 | 출처 | 상태 |
|---|---|---|
| 리포트 목표가 상향/하향 비율 (분위기 온도계) | 텔레그램 채널 요약 (2차 자료) | 데이터 있음, 집계 도구 필요 |
| 채널 시황 3줄 요약, 자주 나온 키워드 | 텔레그램 채널 | 있음 |
| 종목 토론실 언급 증가, 퀀트 시그널(이익 추정치 변화) | 텔레그램 채널 | 있음 |
| 시장 뉴스 헤드라인 | 네이버 증권 뉴스, 구글 뉴스 | 있음 |
- 채널을 **목적별로 분류**한다: `research`(리포트 요약), `market`(시황), `flow`(수급·특징주), `macro`(경제·정책) 등. `config/channels.toml`에 `purpose` 칸 추가 예정 → 사용자가 채널을 추가할 때 목적만 적으면 됨.
- 채널 내용은 항상 "출처: 채널 요약(2차 자료)" 표시.

  책의 "추세 없는 곳에서 추세추종 하지 않는다"를 화면 맨 위에서 바로 보이게 하는 장치.

## ④ 셋업 스크리닝 — "책의 규칙에 맞는 종목"
1. **감시 후보 풀** (저녁): 추세 조건 = 주봉·일봉 정배열, RS 상위, 52주 고점 근처, 시총·거래대금 하한, 테마주 제외
2. **셋업 판정** (저녁): 1stage 상승률, 조정 깊이(상승분 50% 이내)·기간, VCP, 거래량 마름, 매물대 → 돌파 기준가·알림가·1R
3. **장중 감시** (5~10분): 업종 동반 상승 + 기준가 돌파 + 거래량 페이스 → 텔레그램 즉시 알림
4. **종가 확인** (15:10): 돌파 유지·윗꼬리 여부
- 후보 풀의 범위: 처음엔 **섹터 ETF 구성 종목 + 관심종목**으로 시작(수백 개 수준). 전 종목 RS 순위는 KRX 공식 데이터 확보 후.

## ⑤ 기업 이해 — "이 회사는 뭘로 돈을 버나"
- 대상: 셋업이 뜬 종목 + 지수 대표 종목(시총 상위).
- 내용: 사업 한 줄 요약, 주요 제품·매출 구성, 최근 4분기 매출·영업이익 성장, 컨센서스 목표가, 최근 리포트·공시·뉴스, **반대 근거**.
- 출처: DART 사업보고서 '사업의 내용' + 분기 재무(`dart.py fin`), 네이버 컨센서스, 채널 리포트 요약. Claude가 카드로 요약하고 **분기마다 갱신**(매일 새로 만들지 않음 → 저장해서 재사용).

## 구현 순서
1. **데이터 보강**: 지표(선물·유가·금·시장 수급), 채널 목적 분류, 섹터 ETF 도구, 업종 스냅샷 저장
2. **스크리너**: 감시 후보 풀 → 셋업 판정 → 결과를 `data/bus/날짜/*.json`에 저장
3. **기업 카드**: DART 사업보고서 요약, 저장·재사용
4. **대시보드 v1**: 위 JSON을 읽어 HTML 한 장 생성 (정해진 시간마다 갱신)
5. **장중 감시 + 알림**, 이후 포지션 관리
