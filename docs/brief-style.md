# 브리핑 이모지 표기 규칙 (2026-11-03, 사용자 요청: 상향·하향 가독성)

리포트 브리핑·채널 정리·아침 브리핑 모두 같은 기호를 쓴다. 한 줄에 기호는 1~2개까지만(너무 많으면 오히려 안 읽힘).

## 목표가·투자의견 (리포트)
| 기호 | 뜻 | 쓰는 예 |
|---|---|---|
| 🔺 | 목표가 상향 | `🔺 KB 30만→35만 (+16.7%)` |
| 🔻 | 목표가 하향 | `🔻 NH 12만→10만 (−16.7%)` |
| 🆕 | 신규 커버리지(첫 리포트) | `🆕 신한 목표 8만 (현재가 대비 +25%)` |
| ➖ | 목표가 유지 | `➖ 미래 유지 5만` |
| ⬆️ / ⬇️ | 투자의견 변경 (중립→매수 / 매수→중립) | `⬆️ 의견 중립→매수` |

- 기간 머리줄: `🔺상향 a · 🔻하향 b · 🆕신규 c · ➖유지 d`
- 섹터 줄: `🔻 반도체 장비 · 5건 · 평균 −12% · A, B, C`
- 같은 종목에 상향·하향이 섞이면 `🔺2 🔻1`처럼 개수로.

## 주가 등락 (현재가 옆)
- `▲2.3%` 오름 / `▼1.1%` 내림 / `0.0%` 보합 — 목표가 기호(🔺🔻)와 헷갈리지 않게 작은 삼각형을 쓴다.

## 실적·소식 성격 (채널 정리·실적 글)
| 기호 | 뜻 |
|---|---|
| 🟢 | 호재(추정) · 실적 컨센 상회 |
| 🔴 | 악재(추정) · 실적 컨센 하회 |
| ⚪ | 중립 · 컨센 부합 · 판단 보류 |
| 🔥 | 3개 이상 채널이 함께 다룬 소식 |
| 📸 | 채널 사진에서 읽은 숫자 (출처: 채널 이미지) |

- 호재·악재는 Claude 추정이므로 처음 나올 때 "(추정)"을 붙인다.

- ⭐ 보유 종목 · ☆ 관심 종목
