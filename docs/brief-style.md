# 브리핑 이모지 표기 규칙 (2026-11-03, 사용자 요청: 상향·하향 가독성)

리포트 브리핑·채널 정리·아침 브리핑 모두 같은 기호를 쓴다.
**색 원칙(한국식): 빨강 = 오름·좋음, 파랑 = 내림·나쁨** (사용자 요청 2026-11-03). 🔺 빨강 삼각형 / 🔽 파랑 네모 화살표. 한 줄에 기호는 1~2개까지만(너무 많으면 오히려 안 읽힘).

## 목표가·투자의견 (리포트)
| 기호 | 뜻 | 쓰는 예 |
|---|---|---|
| 🔺 | 목표가 상향 (빨강) | `🔺 KB 30만→35만 (+16.7%)` |
| 🔽 | 목표가 하향 (파랑) | `🔽 NH 12만→10만 (−16.7%)` |
| 🆕 | 신규 커버리지(첫 리포트) | `🆕 신한 목표 8만 (현재가 대비 +25%)` |
| ➖ | 목표가 유지 | `➖ 미래 유지 5만` |
| ⬆️ / ⬇️ | 투자의견 변경 (중립→매수 / 매수→중립) | `⬆️ 의견 중립→매수` |

- 기간 머리줄: `🔺상향 a · 🔽하향 b · 🆕신규 c · ➖유지 d`
- 섹터 줄: `🔽 반도체 장비 · 5건 · 평균 −12% · A, B, C`
- **순서: 항상 상향(🔺) 먼저, 그다음 신규(🆕)·유지(➖), 하향(🔽)은 마지막** (섹터 줄·종목 줄·증권사 줄 모두, 사용자 요청 2026-11-04)
- 같은 종목에 상향·하향이 섞이면 `🔺2 🔽1`처럼 개수로.

## 주가 등락 (현재가 옆)
- `▲2.3%` 오름 / `▼1.1%` 내림 / `0.0%` 보합 — 목표가 기호(🔺🔽)와 헷갈리지 않게 작은 삼각형을 쓴다. (텔레그램 글자는 색을 못 넣어서 검정, 웹 트레이딩룸에서는 ▲ 빨강 ▼ 파랑으로 칠해 보인다)

## 실적·소식 성격 (채널 정리·실적 글)
| 기호 | 뜻 |
|---|---|
| 🔴 | 호재(추정) · 실적 컨센 상회 |
| 🔵 | 악재(추정) · 실적 컨센 하회 |
| ⚪ | 중립 · 컨센 부합 · 판단 보류 |
| 🔥 | 3개 이상 채널이 함께 다룬 소식 |
| 📸 | 채널 사진에서 읽은 숫자 (출처: 채널 이미지) |

- 호재·악재는 Claude 추정이므로 처음 나올 때 "(추정)"을 붙인다.

- ⚠️ 리스크 경고(3R 도달, 20일선 이탈, 손절가 근접, CR 한도)
- 🏷️ 업종 분류 확인 부탁
- 💡 Claude 의견 · 🧭 핵심 흐름 · 📌 주요 종목 · 💼 내 종목 · ⚖️ 읽는 법 (섹션 제목)
- 브리핑 맨 끝에 범례 한 줄: `범례: 🔺상향 🔽하향 🆕신규 ➖유지 · ▲▼주가 · 🔴호재 🔵악재(추정) · ⭐보유`

## 시각 기준 (사용자 요청 2026-11-04)
- 💡 의견과 시장 줄의 지수·종목 숫자는 **쓰는 시각의 최신 값**을 쓴다. 장중(평일 09:00~15:30)에 쓰면 `naver_quote.py index`로 오늘 장중 값을 받아 "코스피 x ▲▼x% (오늘 HH:MM)"처럼 적는다.
- 장 시작 전·주말이면 "전일 종가(MM/DD)"라고 밝힌다.
- 채널 글 속 지수 등락은 **그 글이 올라온 날** 기준이다. 00:00~09:00 글의 "코스피 −3%"는 어제 마감 이야기이므로 "어제 마감"으로 구분하고, 오늘 장 숫자와 섞지 않는다.

## 지난 브리핑과 달라진 것 (사용자 요청 2026-11-04, 모든 브리핑)
- 💡 의견 바로 다음에 **🔄 HH:MM 이후 달라진 것** 3~6줄: 직전 브리핑(같은 종류 우선, 없으면 가장 최근 브리핑) 이후 새로 나온 글·숫자 변화·바뀐 판단만. 각 줄 앞에 글 시각.
  - 직전 브리핑 찾기: `reports/` 아래 가장 최근 파일 (아침 → 전날 리포트 오후, 리포트 오전 → 오늘 아침, 리포트 오후 → 오늘 리포트 오전, 채널 정리 → 오늘 마지막 채널 정리나 리포트). 읽어서 비교한다.
  - 이미 다룬 내용은 반복하지 않고 본문에서도 짧게. 새 소식이 거의 없으면 "큰 변화 없음"이라고 솔직히 쓴다.
- 그 아래 **🌡️ 분위기 흐름** 한 줄: 직전 브리핑 때 분위기 → 지금 (예: 위험 회피 → 반도체 반등에 일부 회복). 오늘 첫 브리핑이면 어제 마감 → 오늘 아침.
- 웹 브리핑 탭 맨 위 "흐름"은 하루 브리핑들의 💡 첫 줄을 시간순으로 보여 준다. 그래서 💡 첫 줄은 그 시점의 핵심 한 문장으로 쓴다.

## 읽기 쉬운 글쓰기 (사용자 요청 2026-11-09, 모든 브리핑·채널 정리·리포트 정리)
웹 화면이 **문장마다 줄을 바꿔** 보여 준다(`다.` `요.` 뒤). 그래서 글을 쓸 때부터 문장을 짧게 끊는다.
- **한 문장 = 한 가지 말.** 한 문장은 60자 안팎, 길어도 두 줄 이내. 쉼표로 이어 붙이지 말고 마침표로 끊는다.
- **결론(숫자)을 문장 앞에.** 이유·근거는 다음 문장. 같은 말을 두 번 쓰지 않는다.
- **💡 의견은 라벨 4줄**: `핵심:` `내 종목:` `반대 근거:` `🔄 HH:MM 대비:` (필요할 때만 `추가:`). 한 줄은 문장 2~3개 이내.
- **괄호는 한 줄에 1개까지.** 출처·시각·증권사 부연은 문장 끝에 한 번만 붙이고, 문장 중간에 끼우지 않는다.
- **한 줄에 숫자 4개↑, 종목 4개↑이면 줄을 나눈다.** 많은 종목은 상위 3~4개만 쓰고 "외 N건".
- 목표가는 `145,000→125,000`처럼 **변화만**. 증권사는 중요한 1~2곳만 이름을 쓴다.
- **어투는 "~입니다"로 통일한다 (사용자 확정 2026-11-13).** 모든 브리핑·체크포인트·정리·보고서·웹 설명 글이 같다.
  - 맺음말은 `~입니다 / ~했습니다 / ~합니다 / ~없습니다`. `~다 / ~한다 / ~이다 / ~본다`처럼 끝내지 않는다.
  - 명사로 끝내도 된다(예: "하향 71 대 상향 11"). 어미를 아예 쓰지 않는 쪽이 짧으면 그렇게 쓴다.
  - 같은 어미가 네 줄 넘게 이어지면 한 줄은 명사로 끝내 단조로움을 피한다.
- 홍보·반복·과거 정정·단순 나열은 뺀다(기존 '중요한 순' 원칙 그대로).
