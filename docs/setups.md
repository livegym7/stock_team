출처 표시: **[책]** = 사용자가 준 Ch.04 추세추종 트레이딩, **[일반]** = 책에 이름만 나오고 정의는 없어 원저자(미너비니·오닐·모랄레스/카커)의 일반적 정의를 옮긴 것, **[기본값]** = 책에 숫자가 없어 Claude가 제안한 값 (사용자 확정 전).

## 1. 셋업 종류
| # | 이름 | 모양 | 판정 조건 | 출처 |
|---|---|---|---|---|
| A | **박스·불 플래그 돌파** (기본형) | 강한 상승 → 깃발·박스 모양 조정 → 박스 상단 돌파 | 조정이 1stage 상승분의 50% 이내, 조정 3주↑, 박스는 가로로 길고 세로로 좁을수록 좋음 | [책] / 3주는 [기본값] |
| B | **컵 앤 핸들** | U자 바닥 + 오른쪽 위 작은 손잡이 조정 | 컵 7~65주, 깊이 12~33%, 손잡이 깊이는 컵의 1/3~1/2, 돌파 시 거래량 증가 필수 | [책] |
| C | **VCP** (변동성 축소) | 조정 폭이 점점 작아짐 (예: 25%→12%→6%) | 되돌림 폭 2~4번 연속 감소, 마지막 폭 한 자릿수, 거래량도 감소 | [책] / 횟수는 [일반] |
| D | **HTF** (하이 타이트 플래그) | 짧고 가파른 급등 뒤 짧은 조정 | 8주 안에 +100%↑, 조정 5일~3주, 조정 폭 20% 이내 | [책] |
| E | **신고가 돌파** | 52주·역사적 신고가 갱신 | ① 바로 돌파 ② 여러 번 실패 후 돌파(VCP형) ③ 컵 앤 핸들형 | [책] 가장 선호 |
| F | **로우 치트** (조기 진입) | 베이스 아래쪽에서 짧게 쉬는 구간을 먼저 돌파 | 베이스 하단 1/3 근처의 짧은 횡보 고점 돌파, 손절 짧게 | [책] 이름만 / 정의 [일반] 미너비니 |
| G | **포켓 피봇** (조기 진입) | 베이스 안에서 거래량 터진 양봉 | 상승일 거래량 > 직전 10일 중 하락일 최대 거래량, 10일선 근처 | [책] 이름만 / 정의 [일반] 모랄레스·카커 |
| H | **이벤트 진입** | 셋업 자리는 아니지만 강한 날 | 거래량 터진 장대양봉, 섹터 전체 상승일 | [책] |

- 책의 강조: 패턴 이름보다 **"강한 상승 → 건전한 조정 → 돌파"라는 원리와 구조**가 중요. 사선 돌파·쿨라매기 셋업은 숙련자용이라 제외.
- F·G는 "펀더멘털을 알 때 2% 부족한 구간에서도 진입"하는 방법 [책] → 처음엔 **알림 등급을 낮게**.

## 2. 돌파 기준가 (어디를 뚫어야 하나)
- 선이 아니라 **매물대(거래가 많이 쌓인 가격대)를 박스로** 본다. 윗꼬리·몸통이 아니라 "시체가 쌓인 곳" [책]
- 기준가 = 현재가 바로 위 매물대 상단 또는 조정 구간 고점 (`tools/chart.py` 거래대금 매물대) [기본값]
- 알림가 = 기준가 -2% [책: 1~2% 전 알림]

## 3. 돌파 확인 (진짜 돌파인가)
| 조건 | 기준 | 출처 |
|---|---|---|
| 가격 | 기준가 위 (갭 상승 돌파 포함) | [책] |
| 거래량 | 평소의 1.5배↑ (장중엔 시간 보정 페이스) | [책] "많은 거래량", 1.5배는 [기본값] |
| 캔들 | 장대양봉, 종가까지 유지 (윗꼬리 길면 실패 의심) | [책] |
| 업종 | 같은 업종 동반 상승이면 최고 등급 | [책] 섹터 움직임 |
| 수급 (장후) | 기관 순매수 ≥ 거래량 10%, 외국인·투신·연기금 | [책] |

## 4. 돌파 뒤 (참고: 보유 관리)
- 손절 -1R (예: 7%), 3R 도달 시 50% 매도 → 손절선 본전, 2R 또는 +18~19%에서 본전 손절로 상향 [책]
- 추세 이탈: 급등주 5일선 / 추세주 20일선 / 완만한 종목 50·60일선, 섹터 ETF 20일선 이탈 [책]
- 즉시 축소·매도: 클라이맥스(신고가 + 역대급 거래량 + 윗꼬리 음봉), 고점 -10% 장대음봉, ATR 크기 음봉 3연속 [책]
- 불타기: 1R 도달·추가 셋업·신고가 등에서 30~50% → 15~20% → 10%, 물타기 금지 [책]
