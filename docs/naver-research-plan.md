# 네이버 리서치 산업·전략 리포트 깊게 읽기 — 깔때기 설계 (2026-11-11, 전략 문서 → 같은 날 구현: `tools/research_cards.py`, `/research-cards`, 자료실 예약 교체, 웹 '리포트 카드' 탭)

> 코드 아님. 사용자 요청: "채널 요약은 기업 리포트 중심이라 네이버 산업분석을 더 깊게, 토큰은 적게, 양은 많이."
> 절대 규칙: PDF 원본은 저장소에 넣지 않는다(텍스트 캐시는 `data/cache/`, 커밋 안 함). 저장은 카드(요약·숫자·링크)만.

## 1. 실측 (2026-11-11)
| 항목 | 값 | 뜻 |
|---|---|---|
| 산업분석 리포트 | 평일 15~25건, 월요일 46~66건 | 주 약 120건 |
| 투자전략 리포트 | 평일 12~15건 | 주 약 70건 |
| 네이버 목록의 무료 요약 | 중앙값 약 500자 | 토큰 0으로 이미 확보 |
| 본문 글자 수 | 300자(본문 비공개)~17,000자, 보통 6,000~13,000자 | 리포트 1건 전부 읽기 ≈ 5천~1.2만 토큰 |
| 지금 읽는 양 | 하루 2건 (Sonnet, 전문) | 주 10건 = 전체의 5% |
| 추출 품질 | `pdftotext` 기본 모드라 **2단 레이아웃 문장이 섞임** | 모델이 재조립하느라 토큰·오해 둘 다 늘어남 |

결론: 전부 읽으면 하루 약 25만 토큰. 그럴 필요 없이 **4단 깔때기**로 전부 '보고', 일부만 '읽고', 소수만 '깊게' 읽으면 된다.

## 2. 깔때기 4단 (토큰은 아래로 갈수록 비싸고, 건수는 줄어든다)

```
Tier 0  토큰 0   전부 (주 190건)   수집·본문 추출·자동 카드 초안·신규성 점수·시리즈 중복 제거
Tier 1  Haiku    새 내용 15건/일   구조화 카드 (논지·숫자 3·근거 2·위험 2·입장·새 주장)
Tier 2  Sonnet   2~3건/일          질문 주도 깊이 읽기 (띔의 질문 5개에 본문 발췌로 답하기) + 반대 의견 1건 보장
Tier 3  Opus     주 1회            카드 100~150장 집계 → 전략 보고서 '이익·말' 축, 업종 지식 노트 갱신
```

### Tier 0 — 토큰 0, 전부
- 매일 산업·전략 전체 목록 수집(이미 함) + **본문 텍스트 추출을 전부**(캐시, 커밋 안 함). 300자짜리(본문 비공개)는 '요약만' 표시.
- `pdftotext -layout`으로 바꿔 2단 섞임을 줄이고, 머리말·꼬리말·Compliance 문단·반복 표지는 규칙으로 잘라낸다 → 모델에 들어가는 글자 30~40% 감소, 품질은 오름.
- **자동 카드 초안**(규칙만): 증권사·애널리스트·업종(제목+본문 키워드 → `sector_taxonomy`)·쪽수·글자 수·언급 종목(universe 매칭)·숫자 상위 10개(%, 억, 달러, 톤, GW 같은 단위 붙은 수)·표 추출(숫자가 3개↑인 줄 묶음).
- **시리즈 판별**: 제목에 Daily/Weekly/Monthly/주간/데일리가 있거나 같은 증권사·같은 업종이 7일 주기로 반복되면 시리즈. 시리즈는 **지난 호와 문단 단위 diff**를 떠서 새 문단만 남긴다(주간 리포트는 보통 60~80%가 반복).
- **신규성 점수**: 지난 30일 카드와 n-gram 유사도. 비슷한 논지가 이미 있으면 낮게, 처음 나오는 키워드·숫자가 많으면 높게.
- **반대 의견 신호**: 현재 띔 키워드가 있으면서 '하향·보수적·과도·리스크·둔화' 같은 부정 어휘 밀도가 높으면 표시.
- 산출물: 웹 '자료실'에 **산업·전략 리포트 전체 목록**(카드 초안 + 네이버 요약 500자)이 매일 올라간다. 지금처럼 읽은 2건만이 아니라 **190건 전부가 보인다.**

### Tier 1 — Haiku, 하루 10~15건
- 대상: Tier 0에서 시리즈 반복분·중복을 뺀 '새 내용' 리포트. 월요일은 많으니 상한 20건.
- 입력은 전문이 아니라 **핵심 구간만**: 첫 2쪽(요약·결론이 대개 앞에 있음) + 추출한 표 + 마지막 결론 문단 + 띔 키워드 주변 ±600자. 건당 3~4천 토큰.
- 출력(구조화 카드, 15줄 이내): 논지 한 줄 · 입장(강세/중립/약세) · 핵심 숫자 3(단위·기준 시점) · 근거 2 · 위험 2 · 관련 업종·종목 · **지난 카드 대비 새 주장**(Tier 0이 붙여 준 유사 카드 제목을 보고 "무엇이 새로운가" 한 줄) · 깊이 읽을 가치(상·중·하와 이유).
- 비용: 15건 × 4천 = 하루 약 6만 Haiku 토큰(현재 Sonnet 2건 전문 읽기와 비슷하거나 더 싸다).
- 산출물: `data/research/cards/날짜/nid.json`. 웹 자료실 목록 줄에 카드 요약이 붙고, '업종별로 묶어 보기'가 가능해진다.

### Tier 2 — Sonnet, 하루 2~3건 깊게 (지금 자료실 역할의 개선판)
- 선택 기준(규칙, 토큰 0): Tier 1의 '깊이 읽을 가치 상' × 신규성 × 띔·관찰 풀 관련. **하루 1건은 반드시 반대 의견이거나 스코어카드 하위 업종**(확증 편향 방지).
- **질문 주도 읽기**: 전략 보고서의 띔마다 체크포인트·무효 신호에서 질문 5개를 미리 뽑아 둔다(예: "DRAM 계약가 4Q 전망 숫자는?", "LTA 해지 조건은?"). 깊이 읽기는 전문을 통째로 넣지 않고, 질문 키워드 주변을 발췌(토큰 0)해 **질문에 답하는 형식**으로 쓴다. 답이 본문에 없으면 "없음"이라고 적는다. 건당 토큰이 절반으로 줄고, 전략 보고서가 바로 쓸 수 있는 형태가 된다.
- 지금의 자료실 형식(요약·논리·숫자·반대 근거·checked)은 유지. 쪽수 표기 유지.

### Tier 3 — Opus, 토요일 전략 보고서
- 카드 100~150장을 **업종별로 집계한 표**를 먼저 받는다(토큰 0): 업종 × {카드 수, 입장 분포, 반복된 주장 상위 3, 새로 나온 주장, 핵심 숫자의 주간 변화}. Opus는 이 표 + Tier 2 요약 + 숫자(4검증)만 읽는다.
- **업종 지식 노트**(`data/research/notes/업종.md`, 살아 있는 문서): 업종마다 '지금 시장이 믿는 서사 / 핵심 숫자 시계열 / 찬반 / 마지막 갱신'을 주 1회 갱신. 기업 카드·채널 정리·전략가가 공통으로 참조하는 '큰 흐름 메모리'가 된다. 31일 치를 다시 읽지 않아도 누적된다.

## 3. 토큰 어림 (하루)
| 지금 | 제안 |
|---|---|
| Sonnet 2건 전문 ≈ 3~4만 | Tier 0: 0 / Tier 1 Haiku 6만(단가 낮음) / Tier 2 Sonnet 3건 발췌 ≈ 3만 / Tier 3 주 1회 Opus +5만 |
| 읽은 리포트 2건, 보이는 리포트 2건 | **구조화 카드 15건, 깊이 3건, 보이는 것 전부(190건/주)** |

비용은 비슷하거나 소폭 증가, 범위는 7~10배. 가장 큰 절감 포인트는 ① 전문 대신 핵심 구간 ② 시리즈 diff ③ 질문 주도 발췌 ④ -layout 추출 네 가지이며, 모두 토큰 0 처리다.

## 4. 화면·흐름에 닿는 곳
- 자료실: '전체 목록(카드)' 탭이 기본, '깊이 읽음' 탭이 지금의 문서 목록. 업종별 묶음·입장 필터(강세/약세)·'새 주장만' 필터.
- 전략 메뉴 띔 보드 옆에 **업종 지식 노트** 링크.
- 채널 정리(플로우 데스크)가 기업 리포트 중심인 약점은 이 깔때기가 산업·전략 쪽을 맡아 보완한다. 채널 쪽은 그대로.

## 5. 지키는 선
- PDF 원본·전문 텍스트는 저장소에 올리지 않는다(캐시만). 카드에는 요약·숫자·쪽수·링크.
- 카드의 숫자는 "증권사 날짜 p.n"을 붙이고, 모델이 읽지 않은 리포트(Tier 0만)는 '자동 초안' 꼬리표.
- 매수·매도 표현 금지는 카드에도 적용(리포트의 투자의견은 인용으로만).

## 6. 만드는 순서 (확인 뒤)
1. `pdftotext -layout` + 머리말·Compliance 제거 + 전체 본문 캐시 (토큰 0) — 반나절
2. 자동 카드 초안·시리즈 diff·신규성·반대 의견 신호 → 웹 자료실 전체 목록 — 하루
3. Tier 1 Haiku 카드 예약(평일 18:40, Haiku 대화) + 카드 저장 형식 — 반나절
4. Tier 2 선택 규칙 교체(반대 의견 1건 보장) + 질문 주도 읽기(전략 보고서 질문 파일) — 반나절
5. Tier 3 업종 집계표 + 업종 지식 노트 + 전략 보고서 스킬에 연결 — 하루

## 7. 결정 (2026-11-11 사용자 확정)
- Tier 1은 산업·전략만 / 깊이 3건 중 1건 반대 의견 고정 / 시리즈는 차이(새 문단 비율)만 읽음

## 7-원안. 결정해 주실 것(기록용)
1. Tier 1 범위: 산업·전략 리포트만(제안) / 기업 리포트 중 관찰 풀 종목도 포함.
2. 하루 깊이 읽기 3건 중 1건을 '반대 의견·비주류 업종'으로 고정할지.
3. 시리즈(Daily·Weekly) 리포트는 diff만 읽기(제안) / 아예 제외.
